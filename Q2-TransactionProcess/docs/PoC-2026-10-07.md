# Q2 - Transaction Processing and Control Flow
## What the program does
The program implements a mobile transaction system terminal for an agent.

```
===== MOBILE MONEY TRANSACTION SYSTEM =====

1. Deposit
2. Withdraw
3. Check Balance
4. Transaction Summary
5. Exit
```

The program refuses transactions that make no sense like a non-positive amount, or a withdrawal larger than the balance. the system also keeps a count of how many deposits and withdrawals actually *succeeded*.

### 2. Data types and variables

The choice of type is deliberate:

- `double balance`, `double amount` : Floating point is used so that
  fractional amounts can never be silently truncated because RWF is a zero-decimal currency, so amounts are *displayed*
- `int deposit_count`, `int withdrawal_count` : these are counters. They are whole numbers that only ever increase, so `int` is exactly right.
- `int choice` : the menu selection, read with `scanf("%d", ...)`.
- `int *deposit_count` (a pointer parameter) : passed to `deposit()` so the
  function updates the caller's counter directly, instead of returning two values.

### 3. How the program uses conditionals

Conditionals appear in two places, doing two different jobs.

**a) `switch` : dispatch a menu operation.** The selected choice selects exactly
one branch out of five:

```c
switch (choice) {
case 1: balance = deposit(balance, &deposit_count); break;
case 2: balance = withdraw(balance, &withdrawal_count); break;
case 3: printf("Current balance: %.0f RWF\n", balance); break;
case 4: /* print the summary */                       break;
case 5: printf("System terminated.\n");                break;
default: printf("Invalid choice. ...\n"); continue;
}
```

**b) `if` : validate each transaction.** `withdraw()` uses *guard clauses*: each
`if` handles one reason to reject the transaction and returns immediately, so the
happy path is not buried inside nested `else` blocks:

```c
if (amount <= 0) {                      /* invalid transaction 1 */
  printf("Transaction rejected: withdrawal amount must be positive.\n");
  return balance;                       /* balance is left untouched */
}
if (amount > balance) {                 /* invalid transaction 2 */
  printf("Transaction rejected: Insufficient balance.\n");
  return balance;
}
```

Here balance is only modified *after* both guards have passed, so a rejected transaction can never corrupt the balance.

### 4. How the program uses loops

The whole menu runs inside one `while (1)` loop, which is an intentional
*infinite* loop because we want that the agent be able to keep transacting indefinitely. The
loop is not exited by its condition but by an explicit `break` when the agent
chooses Exit:

```c
while (1) {
  printf("\nEnter choice: ");
  ...
  if (choice == 5) {
    break;                /* this is the only way out of the menu loop */
  }
}
```

### 5. How the program uses `break`

`break` is used for two *different* purposes, and the distinction is important:

- **To leave the `switch`.** Each `case` ends with `break`, so that executing one
  case does not fall through into the next one. This `break` leaves only the
  `switch`, not the loop.
- **To terminate the loop.** After the `switch`, `if (choice == 5) break;` exits
  the `while` loop itself, ending the program cleanly.

```c
    case 1:
      balance = deposit(balance, &deposit_count);
      break;              /* break #1: leaves the switch only */
    ...
    if (choice == 5) {
      break;              /* break #2: leaves the while loop, ending the program */
    }
```

### 6. How the program uses `continue`

`continue` abandons the current iteration and jumps straight back to the top of
the loop : that is, straight back to the menu : which is exactly the behaviour
the brief asks for when invalid input is detected. It is used twice:

```c
    /* Typed something that is not a number at all. */
    if (scanf("%d", &choice) != 1) {
      discard_line();
      printf("Invalid choice. Please enter a number from 1 to 5.\n");
      continue;           /* back to the menu */
    }
    ...
    default:
      printf("Invalid choice. Please enter a number from 1 to 5.\n");
      continue;           /* back to the menu */
```
